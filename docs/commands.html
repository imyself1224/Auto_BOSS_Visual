指令 作用
📮投递
/投递 实发，投到平台额度用完（= greet --auto）
/投递 10 实发，本次最多 10 条
/演练 只筛选不发送，默认 5 条

🎓条件设置（设定一次，一直沿用）
/学历 看当前学历设置
/学历 硕士 只看岗位要求正好是硕士的岗位（拼成 BOSS URL 的 degree=204）
/学历 不限 取消学历限制
/薪资 看当前日薪下限
/薪资 300 设定日薪下限；也认 月薪8000 / 8k（自动折成日薪）
/薪资 不限 不按薪资筛 （BOSS 没有日薪档，日薪由程序按卡片薪资精确比较）
/关键词 看当前检索关键词（config.toml 的或 QQ 指定的）
/关键词 大模型算法 Agent 设定检索关键词，之后一直沿用
/关键词 清空 恢复 config.toml 的 [search].queries
/配置 看当前生效的全部条件（学历 / 薪资 / 关键词 / 其他硬条件）
/配置 清空 恢复最开始的状态：关键词用 config.toml、学历不限、日薪 300
🔄账号
/切换 在本人版 / 爸妈版之间切换（先关当前 Edge，再打开另一个）
🔧查看与控制
/状态 是否在跑、跑了多久、今日已投多少、当前学历 / 薪资
/今日 今天投了哪些岗位
/统计 今日各状态计数 + 最近 5 次运行
/日志 20 最近一份运行日志的末尾 20 行
/停止 当前这条处理完就收尾；150 秒没退出就强制结束
/重启 / 关机 60 秒后重启 / 关闭电脑
/取消 撤销还没执行的重启 / 关机
/帮助 发送投递相关指令文本 + 本指令表图片（一条消息）
