# 求职者画像与可投岗位族

> 示例文件：一位虚构的「后端 + 大模型应用」方向学生。
> 复制成 `resume/kb.md` 后按自己的简历改写（或按 README 里的提示词让 DeepSeek 生成）。
>
> 这段文字是判断岗位是否可投的**唯一依据**。扫描到岗位后逐条对比，
> 落入下面任一岗位族 = 可投，按「投递优先级」决定先后。

## 核心岗位族

- **LLM 应用算法工程师 / RAG 工程师**
  RAG 全流程、文档切分、向量检索（FAISS / Milvus）、重排序、Prompt 工程、
  LangChain。（对应项目：校园知识库问答助手）

- **LLM Agent 开发工程师**
  工具调用、多 Agent 编排、LangGraph、Function Calling、评测。（对应项目：课程助教 Agent）

- **Python 后端工程师**
  FastAPI、Django、MySQL、Redis、Docker、RESTful API、异步任务队列。
  （对应：某科技公司后端实习）

## 相邻岗位族

- **AI 应用开发 / 全栈工程师**
  Vue / React 前端 + Python 后端，能独立交付一个带模型调用的 Web 应用。

- **数据开发 / 数据分析**
  SQL、Pandas、ETL、报表。（对应：课程项目、实习中的数据清洗工作）

- **测试开发**
  pytest、接口自动化、CI。

- **产品经理**
  AI 产品 / 大模型应用产品方向。

## 投递优先级

- **最匹配**：LLM 应用 / RAG、LLM Agent 开发
- **次匹配**：Python 后端、AI 应用开发 / 全栈
- **可转投**：数据开发 / 数据分析、Java 后端
- **产品**：AI 产品经理、产品实习生
- **测试**：测试开发、软件测试
  —— 产品、测试两档只看岗位方向归档；薪资门槛由程序判断，你不用管薪资

## 明确不投

- 纯 CV / 自动驾驶 / SLAM / 芯片 / 嵌入式
- 销售、运营、客服、HR 等非技术岗
